# Roboto Bold

Unmodified `android/static/Roboto-Bold.ttf` from Google Fonts' Roboto Classic
v3.016 release: https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.016

Used by the melody interval card to match Android's bold sans-serif appearance.
The SIL Open Font License and copyright notice are in `OFL.txt` and shipped with
the font. Palatino remains the default for Roman numerals and scale degrees.
