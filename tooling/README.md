# Tooling

This directory contains development and operational support for the Acquiring
applications. It is not a fourth application or a shared runtime layer.

- `_Debug_testing/` — focused debugging and regression utilities
- `_Decode_oracle/` — offline chord-decoding oracle and corpora
- `_Research_testing/` — catalog, research, and compatibility checks
- `_Reference/` — retained implementation references
- `_Trash/` — retained historical scratch artifacts pending deliberate review
- `commands/` — repository-level launch, catalog sync, and recovery commands
- `lib/` — Node support modules used by the web server and catalog tooling
- `scripts/` — cross-platform contract and data-root validation

Run commands from the repository root unless a utility documents otherwise.
