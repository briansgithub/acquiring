# Historical Android-to-iOS commit roadmap

The original commit-by-commit checklist was superseded on September 4, 2026.
It replayed intermediate Android redesigns, combined unrelated changes in single
items, and sometimes treated existing Swift logic as completed UI.

Use [porting-plan.md](porting-plan.md) as the only active implementation plan.
It preserves Android first-appearance order while implementing each surviving
feature once in its final production form. Historical details remain available
in Git before this replacement.
